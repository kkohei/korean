# メニューバーに「韓」が住んでいる ── 日↔韓ほんやくアプリを、AIと一緒にゼロから作ってリリースするまで

> 「日本語をサッと、でも“ちゃんとした”韓国語にしてくれる、邪魔にならない小さなMacアプリが欲しい」
> ── そんな思いつきから、本当にアプリができてリリースするまでの記録です。

---

## 1. きっかけ：欲しかったのは「小さくて、賢い翻訳ツール」

韓国語をやりとりする機会があって、ブラウザの翻訳サイトを毎回開くのが地味に面倒でした。

欲しかったのはこんなアプリです。

- Macに**常駐**していて、いつでもサッと使える
- でも画面の邪魔をしない、**小さなウィンドウ**
- ただ機械翻訳するだけじゃなく、**固有名詞や専門用語までネットで調べて“正解”を出す**

既製のアプリで「これだ」というものがなかったので、**自分で作ってみることにしました**。
（ちなみに私はバリバリのエンジニアではありません。今回は **AI（Claude Code）とペアプログラミング**しながら進めました。）

---

## 2. 技術の方針：Swiftネイティブ × Claude API

最初に決めたのは2つ。

**① 見た目と常駐：macOSネイティブのメニューバーアプリ**
Electronのような重い作りではなく、SwiftUIの `MenuBarExtra` を使って、メニューバーに小さく常駐する形に。Dockにアイコンを出さない「アクセサリアプリ」にして、徹底的に“邪魔にならない”を狙いました。

**② 翻訳の頭脳：Claude API ＋ Web検索ツール**
ただの機械翻訳ではなく、**ClaudeにWeb検索をさせて、人名・地名・作品名・流行語などを実際の表記で確認してから訳す**構成にしました。これが「正解を導きたい」という当初の願いの核です。

---

## 3. 作っていく：MVPから、こだわりを足していく

### まずは動くものを（MVP）
- メニューバーの「韓」アイコンをクリックすると小窓が開く
- 日本語を入力 →「翻訳」or `⌘+Return` で韓国語が出る
- APIキーはMacの**キーチェーン（金庫）に安全に保存**

ここまでで「ちゃんと翻訳できる」状態に。

### ウィンドウを“自由”にする
最初はメニューバーにくっついた小窓でしたが、「**デスクトップの好きな場所に置きたい**」と思い、独立したフローティングウィンドウに作り替えました。ドラッグで自由に動かせて、📌で最前面に固定もできます。

### デザインに“好き”を込める
ここが一番楽しかったところ。最初は**ターミナル風**にしました。

- 半透明グレーの背景（背後がぼけて透ける）
- **蛍光グリーンの等幅フォント**
- メニューバーの「韓」も蛍光グリーン

“黒い画面に緑の文字”のあの雰囲気です。さらに、

- 背景の透け具合・文字色を**スライダーで微調整**
- **配色プリセット**も用意（ターミナル緑だけでなく、**ローズゴールド×ベージュ／サクラ／ラベンダー／シャンパン**など、やわらかい色合いも）

道具は毎日使うものだから、**気分で見た目を変えられる**のは大事だと思っています。

### 双方向に
「韓国語→日本語もしたい」となり、⇄ボタン一つで**日↔韓を切り替え**られるように。もちろん逆方向でもWeb検索で固有名詞を確認します。

## 5. リリースまで：配る、ということ

作って終わりではなく、**人に渡せる形**にするのが意外と大変でした。

### `.dmg` にまとめる
ビルドした `.app` を、ドラッグでApplicationsに入れられる **`.dmg`** に。ワンコマンドで作れるスクリプトを用意しました。

### ダウンロードページ＆GitHub Releases
- GitHub Releases に `.dmg` を置いて、固定のダウンロードURLを発行
- **GitHub Pages**でターミナル風のダウンロードページも作成

### 「APIキー問題」をどう設計するか
配布で一番悩んだのがここ。**アプリにAPIキーは含めない**設計にしました。

- キーは**各自が自分のものを取得して、自分のMacに保存**する
- だから配布ファイルにキーは入らず、作者（私）に課金も来ない＝安全

その代わり、受け取った人が困らないように、**インストール〜APIキー取得〜使い方〜FAQ**まで丁寧に書いた**説明書（「はじめにお読みください」）をdmgに同梱**しました。
