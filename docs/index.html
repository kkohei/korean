日韓翻訳

Mac のメニューバーに常駐する、日本語 ⇄ 韓国語の翻訳アプリ。
ネット検索で固有名詞まで正確に翻訳します。

⬇ ダウンロード（.dmg）

macOS 13 (Ventura) 以降 / Apple Silicon・Intel 対応

インストール手順

  1. ダウンロードした KoreanTranslator.dmg を開く
  2. 表示された アプリのアイコンを「Applications」へドラッグ
  3. 「アプリケーション」フォルダから 日韓翻訳 を起動
  4. 初回に「開けません」と出たら、アプリを 右クリック → 開く → ダイアログで 開く
  5. メニューバーの 緑の「韓」 をクリック → ⚙設定で Anthropic APIキー を入力

APIキーの取得

  • console.anthropic.com でサインアップ
  • Billing でクレジットを購入（最低 $5〜。1回の翻訳は数円程度）
  • 「API keys → Create Key」で sk-ant-... を発行し、アプリの⚙設定に貼り付け

「開けません」がどうしても消えないとき

ターミナルで次を実行してください：

xattr -dr com.apple.quarantine /Applications/KoreanTranslator.app
